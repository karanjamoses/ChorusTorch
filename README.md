# ChorusTorch

ChorusTorch is a distributed, real-time data processing engine with auto-scaling capabilities and pipeline orchestration.

With ChorusTorch, you get a lightweight tool that stays out of your way.

**What you get**

- ChorusTorch is a distributed, real-time
- data processing engine with auto-scaling
- capabilities and pipeline orchestration

## Key Features

## Technology Stack

- javascript
- javascript framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ChorusTorch.git`
2. `cd ChorusTorch`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ChorusTorch, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
